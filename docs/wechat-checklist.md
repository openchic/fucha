# 微信兼容性检查清单

用 `pnpm dev` 打开一篇覆盖下列内容的文章，选好主题后点击「复制」。粘贴到公众号草稿，保存后重新打开，并在微信客户端检查窄屏与深色模式。复核不同主题时使用同一篇文章，方便对照预览。

| 项目 | 预期 |
| --- | --- |
| 标题与分割线 | 标题层级、字重、装饰和间距随主题，分割线保持可见。 |
| 列表 | 有序和无序标记、缩进及间距保留。首项以粗体开头时，剩余内容仍属于同一项。 |
| 引用 | 背景、圆角和内距随主题，左边条只显示一次，末段下方无额外空白。 |
| 代码块 | 语法色、缩进和文件名分隔线保留。长行可触摸横滑，深色模式下文字和底色清晰。 |
| 表格 | 表头与边框随主题。短表铺满容器，宽表在表格框内横滑。 |
| 图片 | 图片与宽度保持正常，窄屏下不撑破正文。缺失或超过 5 MB 的图片显示位图占位，其他内容正常。分别检查 WebP 和 AVIF。 |
| 内嵌 SVG | 图形、虚线、文字与尺寸正常，实色标签无黑块，字体回退后仍可读。 |
| 页面留白 | 默认使用微信的左右留白，主题配置的额外内距只叠加一次。 |
| 外链 | 正文外链保留文字，产物没有来源行或外部链接。 |

`pnpm verify` 检查 Electron 中的导出结构与内联样式。公众号草稿保存后的代码块和表格横滑、图片宽度及格式、SVG、引文、列表、留白与微信深色模式仍需人工复核。

导出约束见 [微信导出规格](../openspec/specs/wechat-export/spec.md)。
