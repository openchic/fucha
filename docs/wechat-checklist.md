# 微信兼容性检查清单

目标：导出 HTML 粘贴进公众号后台后，标题、列表、引用、代码块、表格、图片与分割线按主题呈现，格式不被微信编辑器改写。

## 前置

1. `pnpm dev` 启动应用，打开一篇包含标题、列表、引用、代码块、表格、图片和分割线的文章。
2. 在预览信息带确认主题为「雾紫」，点击「复制」，得到内联样式 HTML。
3. 粘贴到公众号后台草稿，逐项对照预览；微信规则变化后从第 1 项重跑。

## 判定

- 2026-11-07 雾紫本地回归通过。360px 的 Electron 预览和导出 HTML 均完整展示三列字词短表，六列表格仅在表格框内横滚。带文件名的代码块保留标题分隔线，代码块外框关闭。
- 2026-11-08 标题复核通过：雾紫 H1/H2 为 20px、24px / 10px 边距、无装饰，H3 至 H6 为统一 16px、18px / 8px 边距。2026-10-30 记录中的 24/12px 与左条属于改造前的旧预设。
- 2026-11-08 内嵌 SVG 导出改为表现属性（`fill` / `stroke` / `stroke-dasharray` / `font-*` 等），并烘平实色 rect mask、给只有 viewBox 的 SVG 补宽高；修复微信保存后矩形变黑、虚线消失、标签压线和生命线被裁。嵌入字体在微信会回退系统字体；待公众号后台保存草稿后复核。
- 2026-11-09 代码块导出把空格替换为不可折叠空格，避免微信保存裁掉高亮 span 前后空白导致 token 粘连和缩进消失；纯文本兜底还原普通空格，待微信保存草稿复核。
- 2026-11-09 列表首项 `<strong>/<b>` 导出改为行内粗体 span，并把整项内容包进无外边距 p，避免微信把首项后的内容包进 section 拆成两行；待微信保存草稿复核。
- 2026-11-09 代码块长行恢复横向滚动（`white-space: pre` / `overflow-x: auto`），先验证微信保存后手指左右滑动是否保留；若仍被裁切，再回退到 `pre-wrap` / `break-all` 自动换行。
- 2026-11-09 引用块导出改为 section 承载同样的内联样式，避免微信给 blockquote 叠加默认左条形成双线；预览仍使用 blockquote，待微信保存草稿复核。

- 2026-11-09 公众号预览两侧留白过宽：导出外层叠加了主题的 `page-padding-left/right`。现把页面 token 左右内距默认改为 0，只表达额外缩进；预览画布另加固定 20px 平台留白，导出由微信正文提供基础左右留白，待重新粘贴确认。
