## Purpose

为桌面应用提供分层、可自动执行、且与真实运行时保真的测试体系：纯逻辑快速反馈，DOM 管线与主进程在真实 Electron 中验证，界面交互覆盖到 hooks 与组件，并让回归在提交前被发现。

## ADDED Requirements

### Requirement: 测试命令入口

仓库 SHALL 提供三条稳定命令：一条运行不依赖 GUI 的单元与组件测试，一条运行需要真实 Electron 运行时的集成测试，一条依次执行类型检查、lint、单元测试与集成测试。任一用例失败时命令 MUST 以非零状态码退出并列出失败用例名称；全绿时 MUST 以零退出。命令名称与用途 SHALL 记录在开发者文档中。

#### Scenario: 单元测试全绿

- **WHEN** 开发者执行单元测试命令且所有用例通过
- **THEN** 进程以 0 退出，并输出通过用例数与耗时

#### Scenario: 存在失败用例

- **WHEN** 任一单元或组件用例断言失败
- **THEN** 进程以非零码退出，并逐条列出失败用例名称与断言差异

#### Scenario: 聚合检查

- **WHEN** 开发者执行聚合命令
- **THEN** 命令依次运行类型检查、lint、单元测试与集成测试，前一步失败时停止并返回非零码

### Requirement: 测试环境分层

测试 MUST 按依赖环境分层：不依赖 DOM 或 Electron 的纯逻辑测试 MUST 能在无图形界面的环境中运行；组件与 hooks 测试 MUST 在具备浏览器语义 DOM 的环境中渲染；依赖真实计算样式、真实 SQLite、`app://` 协议或真实网络行为的断言 MUST 在真实 Electron 运行时中执行，不得用模拟 DOM 替代。

#### Scenario: 无 GUI 环境运行纯逻辑测试

- **WHEN** 在未启动图形界面的环境执行单元测试命令
- **THEN** 纯逻辑用例全部正常执行并通过

#### Scenario: 计算样式一致性断言

- **WHEN** 用例需要比较预览与导出后的计算样式
- **THEN** 该用例在真实 Electron 渲染窗口中读取计算样式，而不是在模拟 DOM 中断言

#### Scenario: 用例顺序无关

- **WHEN** 以不同顺序或并行方式执行同一批用例
- **THEN** 每个用例结果与串行执行时一致

### Requirement: 测试数据隔离

测试 MUST 使用临时目录中的数据库与图片缓存，不得读写真实用户数据目录。每个集成测试用例 MUST 获得独立的用户数据路径；用例结束后 MUST 清理该路径。并行执行的用例 MUST 互不共享数据库文件。

#### Scenario: 不污染真实历史

- **WHEN** 完整执行单元与集成测试
- **THEN** 应用真实用户数据目录中的数据库与缓存内容保持不变

#### Scenario: 并行用例隔离

- **WHEN** 两个集成用例同时运行
- **THEN** 各自读写自己的临时数据库，互不产生记录串扰

#### Scenario: 失败后清理

- **WHEN** 某个用例断言失败或超时
- **THEN** 已创建的临时目录仍被清理，不残留可干扰后续运行的数据库

### Requirement: 测试专用配置缝

主进程 SHALL 支持仅测试使用的用户数据路径覆盖，且仅在被显式设置时生效；未设置时 SHALL 与当前默认路径行为完全一致。该覆盖 MUST NOT 暴露给渲染进程、预加载脚本或用户界面，且 MUST NOT 改变产品的正常启动行为。

#### Scenario: 未设置覆盖时使用默认路径

- **WHEN** 测试覆盖未设置
- **THEN** 数据库仍位于默认用户数据目录下的 `app.db`

#### Scenario: 设置覆盖后隔离

- **WHEN** 测试显式设置用户数据路径
- **THEN** 数据库、图片缓存与偏好全部读写该路径

### Requirement: 覆盖矩阵

测试 SHALL 覆盖以下四类范围，且每类中的错误分支至少有一个用例：

- 纯逻辑：主题 token 校验的数值边界与非法输入、主题 CSS 的解析/作用域/变量解析/白名单校验、站点适配的域名与验证码识别、zip 的畸形与超限输入、窗口尺寸钳制、内置主题不变量。
- DOM 管线：文章提取、净化、SVG 保留、DOM 归一、代码块标题适配、导出结构与计算样式一致性、语法高亮。
- 主进程：schema 逐版本迁移与幂等、损坏与版本过高降级、文章/图片/主题/偏好读写、级联删除与引用保护、主题包往返与非法包拒绝、`app://` 路径穿越、网络失败与图片降级。
- 界面：全部 hooks 的状态流转与失败回滚，交互组件的键盘操作、焦点管理与受控输入边界。

#### Scenario: 错误分支覆盖

- **WHEN** 审查任一上述模块的测试
- **THEN** 其非法输入或失败路径至少存在一个断言，而不只有成功路径

#### Scenario: 新增管线行为

- **WHEN** 往管线中新增一个公开变换或导出规则
- **THEN** 同一变更内包含覆盖其正常与异常分支的用例

### Requirement: 既有断言迁移

现有自建验证脚本中的断言 MUST 在迁移期间保持可执行且全绿。每条断言 MUST 在新分层中有明确归属；迁移完成前 MUST 保留双通路。迁移完成后自建运行脚本 SHALL 被删除，且新体系 SHALL 覆盖同等行为：按领域逐条对照，断言数量不得少于迁移前。

#### Scenario: 迁移期间双通路全绿

- **WHEN** 迁移进行中执行旧脚本与新测试
- **THEN** 两套通路均全部通过

#### Scenario: 迁移完成对照

- **WHEN** 旧脚本被删除
- **THEN** 迁移清单逐条标明每条旧断言对应的新用例，且清单无未归属项

### Requirement: 测试数据与断言风格

测试夹具 SHALL 集中存放并可被多个用例复用，覆盖微信文章、文档站页面与通用文章三类来源。导出产物 MUST 使用结构断言，不得使用包含时间戳或哈希的整文件快照。与时间相关的断言 MUST 只验证顺序或相对关系，不验证绝对时间。

#### Scenario: 导出产物断言

- **WHEN** 断言导出 HTML 的结构
- **THEN** 用例检查标签结构、内联样式与内容顺序，不比对整文件快照

#### Scenario: 时间相关断言

- **WHEN** 用例验证文章列表的排序或访问计数
- **THEN** 断言相对顺序或计数值，不断言具体时间戳

### Requirement: 自动化接线

仓库 SHALL 在提交前自动执行单元与组件测试，且提交钩子 MUST NOT 运行集成测试以保持提交速度。集成测试命令 MUST 能在无图形界面的 Linux 环境中通过虚拟显示运行，以便接入持续集成。

#### Scenario: 提交前拦截

- **WHEN** 开发者执行提交且单元或组件测试存在失败
- **THEN** 提交被阻止并提示失败用例

#### Scenario: 无头环境运行集成测试

- **WHEN** 在无图形界面的 Linux 环境以虚拟显示执行集成测试命令
- **THEN** 集成用例正常启动 Electron 并完成断言
