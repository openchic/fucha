## 5. 界面（preview-ui）

- [ ] 5.1 四态状态机（idle / loading / preview / error）与初始态：居中输入框（占位"请输入一个链接"）紧挨"生成"按钮，回车与点击等价，处理期间按钮禁用；验证：两种提交方式均进入 loading、缩到最小宽度两栏不塌
- [ ] 5.2 加载态：提交后输入区从居中平滑移至左列，右栏同时滑入骨架屏（约 240ms ease-out），三阶段提示（正在请求 / 正在解析 / 正在下载图片）以小字标注在骨架屏内，由主进程进度事件驱动，生成按钮处理期间禁用；验证：位移与滑入同步、三阶段依次出现
- [ ] 5.3 预览态：骨架屏原地淡出为只读正文；左列输入区下方元信息栏（标题、来源链接、作者、发布时间、图片清单，来源与作者固定可见），右栏顶部预留操作栏区域（控件后续 change 填充）；左列输入区可再次提交并直接回到加载态；验证：预览内容不可编辑、布局自加载起保持稳定、重新提交可走通
- [ ] 5.4 最小可读样式基线（正文排版从简，为主题渲染留位）；验证：二十链接样张目视可读
- [ ] 5.5 应用壳配色与视觉基调落 styles/app.css：主色 #8fae96（焦点环、生成按钮、激活态）、辅助色 #eadfcf（面板与骨架屏底）、实底按钮配深色文字；六条基调（留白分组不画框、色彩克制、底色分层不投影、动效短、字号底盘 14/13/16-20/12、控件圆角 6 至 8px）；验证：界面无默认灰残留，应用配色与文章预览样式互不影响
