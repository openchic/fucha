## Purpose

让预览成为公众号最终效果的忠实呈现：按主题 token 渲染，切换即时生效，不因切主题重建文档。

## ADDED Requirements

### Requirement: 预览按主题渲染

预览态正文 SHALL 按当前主题 token 渲染，用户在预览中看到的效果与导出后粘进公众号的效果同源——两条路径共用同一份 CSS 生成逻辑。

#### Scenario: 预览即主题效果

- **WHEN** 预览态加载完成
- **THEN** 正文以当前主题的字体、颜色、块级样式呈现

### Requirement: 切换即时生效

切换主题 SHALL 即时生效于预览，不重新解析文档、不重置图片与滚动状态。主题选择控件 SHALL 位于预览区顶部操作栏右侧首位（复制按钮左侧），本期以内置预设填充。

#### Scenario: 切主题不闪断

- **WHEN** 预览态下切换主题
- **THEN** 样式立即变化，文档内容与滚动位置不变

#### Scenario: 操作栏内切换

- **WHEN** 用户在操作栏的主题下拉中选择主题
- **THEN** 预览即时切换且滚动位置不变

### Requirement: 导出值一致性

预览用 CSS 变量渲染的同时，SHALL 能从同一份 token 生成导出用的具体值样式——任何 token 值在预览与导出两条路径下 SHALL 解析为相同的最终样式。

#### Scenario: 变量与具体值同源

- **WHEN** token 的 primary 颜色变化
- **THEN** 预览（CSS 变量路径）与导出（具体值路径）的对应样式同步变化且一致
